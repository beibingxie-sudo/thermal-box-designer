快速上手

1
载入示例 — 点击左侧底部 📋 载入示例，加载已保存的默认配置（通过「⭐ 存为默认」保存）；若未保存过则加载内置示例
2
运行仿真 — 点击 ▶ 运行热仿真，计算温度分布和风道网络，右侧面板展示完整结果
3
调整优化 — 修改模块位置/功率/材料、增减风扇和散热孔，重新仿真对比效果
4
导出报告 — 点击 📄 导出报告 保存为 txt 文件

界面布局

三栏布局：

  • 左侧 — 参数配置面板（电箱、模块、风扇、散热孔 + 仿真/导出按钮）
  • 中间 — 2D/3D 可视化画布（支持缩放、拖拽、热力图叠加）
  • 右侧 — 仿真结果面板（结果卡片、ICEPAK工况点、详表、分析）

所有左侧区域标题均可点击折叠/展开。

材质与参数推荐配置

下表整合了材质导热/辐射/热阻的联动关系，供选型参考：

壳体材质k
(W/m·K)		εRdev 推荐
(强制风冷)		推荐 Rjc
(典型封装)		适用场景
铜3850.050.10~0.200.1~0.3极高功率 IGBT/SiC 模块散热基板；成本高、重量大，仅用于高端应用
铝合金2000.100.15~0.300.2~0.5伺服驱动器 / 变频器 / 大功率电源 — 工业首选，轻量、便宜
黑化铝2000.850.12~0.250.2~0.5🔥 最佳综合方案：阳极氧化/烤漆后，导热+辐射双高，推荐所有铝壳模块做此处理
钢板500.300.30~0.600.3~0.5开关电源铁壳 / 继电器组 / 接触器 — 成本低，结构强度好
不锈钢160.200.40~0.800.5~1.0食品/医疗设备外壳 — 耐腐蚀但导热差；不适合发热大的模块
塑料0.30.900.60~1.500.5~2.0PLC / IO模块 / 传感器 — 辐射强但几乎不导热，仅适合低功率(<50W)

选型决策链：
① 先选壳体材质 → 自动设定 ε 和导热系数 k
② 根据冷却条件（风扇/自然/封闭）选择 Rdev 档位
③ 根据芯片封装（IGBT模块/MOSFET/塑封IC）补充 Rjc
④ 铝壳模块强烈建议做黑色表面处理（ε 可从 0.10 升到 0.85，零成本增益）

💡 实际案例：200W 伺服驱动器，铝壳 Rdev=0.4，Rjc=0.3。若抛光铝(ε=0.10) → Tj≈200°C；若黑化(ε=0.85) → Tj≈187°C，仅靠黑色氧化就降 13°C，成本几乎为零。

🌀 风扇配置

参数单位说明
安装面—6个壁面（前/后/左/右/上/下）
位置mm沿壁面的位置坐标
直径mm风扇直径（影响绘制和 Pmax 估算）
铭牌风量CFM自由送风风量（ΔP=0）；转换为 L/min 内部计算
方向—进气（吸入）或 排气（排出）
P-Q 曲线自动估算
Pmax = 8 + (dia/80)² × 52 Pa，线性近似 ΔP(Q) = Pmax × (1 − Q/Qmax)
卡片中自动显示 "Qmax=X CFM, Pmax≈Y Pa"
⚠ 重要：必须有进气+排气配对
仅有进气风扇、没有排气（或反之）会导致「风道阻塞」——有效风量骤降至铭牌的 ~8%，散热能力大幅下降。

🔲 散热孔

参数单位说明
安装面—6个壁面
位置mm沿壁面的位置坐标
宽 × 高mm开口尺寸
开孔率%有效自由面积比，越高阻力越小
阻力计算：使用 ICEPAK 薄孔板公式 K = (1−A)/A²，开孔率越低 → 阻力越大 → 实际风量越低。
有效面积 = 宽×高×开孔率。多条散热孔采用并联流阻合并。

🖱 画布操作

2D 俯视图

  • Ctrl + 滚轮：缩放（0.15x ~ 20x）
  • 点击组件/风扇/散热孔：选中（蓝色虚线高亮），信息栏显示名称和操作提示
  • 拖拽：移动选中的元素（风扇沿壁面滑动）
  • 悬停：显示 tooltip（组件温度/风扇参数/散热孔参数）
  • 「居中」按钮：重置缩放和居中

3D 视图（Three.js 渲染 · 正交轨道投影 · 全范围旋转）

  • 渲染内核：3D 视图采用 Three.js（WebGL）进行真实三维渲染，正交相机保证工程视图（正/侧/俯视）无透视变形；若浏览器不支持 WebGL，则自动回退到内置 Canvas-2D 渲染，功能一致。需将 three.min.js 与本文件放在同一目录（已随工具提供）。
  • 快捷视角按钮：默认 / 俯视 / 正视 / 后视 / 左视 / 右视 / 45° —— 一键切换到标准工程视图（正交投影下为正真正视/侧视/俯视，非近似斜投影）
  • 点选对象：点击组件/风扇/散热孔即选中，橙色高亮，左侧属性卡片同步高亮并滚动定位；悬停显示名称、壳温、参数 tooltip
  • 3D 直接拖拽编辑：按住组件拖拽即可调整 X/Y（柜内自动约束，不会超出电箱）；Shift + 拖拽 调整放置高度 Z（保证 Z+H ≤ 柜高）；风扇/散热孔沿所在壁面拖动
  • 旋转视角：在空白区域拖拽，或 右键拖拽 / Alt+拖拽（组件密集处也能转）；水平=yaw，垂直=pitch
  • 俯仰覆盖 ±90°（俯视/仰视全视角）；所有编辑都受 clampCompToBox 柜内约束
  • ← / → 方向键：左右旋转视角(yaw)
  • ↑ / ↓ 方向键：俯仰视角(pitch)
  • 滚轮：3D 下直接缩放（0.15x~20x）；2D 下为 Ctrl + 滚轮
  • 性能：旋转/缩放只更新相机，不重建几何体与纹理；仅当模型、结果或图层变化时才重建场景
  • 「重置视角」按钮：回到默认 3/4 轴测视角；「俯视」按钮则与 2D 俯视严格对齐（X水平、Y向下、比例一致）
  • 旋转以箱体几何中心为轴 → 原地自转、尺寸恒定、不漂移；组件/风扇/散热孔/风道随视角一同正确变换
  • 气流箭头：沿仿真算出的绕行折线路径布置——每条风道拆成多条并行子流线（各自绕开模块），沿路径等弧长放置带杆箭头（细杆+锥头），按局部温度着色（蓝→红，与热力图一致）、按流量决定尺寸，并分多层高度形成立体气流束；不再是「一根直管 + 终点一个圆锥」
  • 密度档位（仅 3D 工具区）：疏 / 标准 / 密 / 极密，控制子流线条数与箭头间距；默认「密」，极密可达上千支箭头并有总量上限保护
  • 流动动画（可关闭）：箭头沿各自折线路径持续循环前进，只更新位置与朝向、不重建几何体，旋转/缩放依然流畅；导出 PDF 时会自动暂停并把箭头复位，保证报告截图稳定
  • 进/排风方向锥：风扇盘中心有朝内（进气）/朝外（排气）的白色锥标，一眼看出气流从哪进、从哪出
  • 停滞区：距所有风道较远的区域以橙色半透明球 + 标签标出，与 2D 视图一致
  • 温度色标：底部「温区」可设置颜色映射范围（默认 0~100°C），2D 热力图、箭头与 3D 温度场/气流箭头共用该配色
  • 箱体以半透明「玻璃」感呈现，内部组件为不透明方块，按深度自动排序保证遮挡正确
  • 组件按壳温着色；底面为真实温度场贴图（50×N 网格逐格映射温度色标范围，默认 0~100°C，可在底部「温区」调整），不再是单一平均色块
  • 模块较多时可取消勾选「名称标签」，只保留几何体，画面更清爽

▶ 运行仿真

点击 ▶ 运行热仿真 后，引擎自动执行以下 10 步流程：

  1. 输入校验 — 至少需要 1 个模块
  2. ICEPAK 工况点求解 — 风扇 P-Q 曲线 ∩ 系统阻力曲线，二次方程求解实际工作风量
  3. 阻力建模 — 散热孔使用 ICEPAK 薄孔板公式；内部按组件填充率估算流阻
  4. 风道网络构建 — N×M 全路径配对，每条路径避障绕行（不穿模块），按 1/R 分流
  5. 逐组件温度计算 — 沿气流方向，Tair = 上游预热 + 发热/C_local；Tcase = Tair + P_net × Rdev；Tj = Tcase + Pheat × Rjc
  6. 辐射散热 — Stefan-Boltzmann 定律，按发射率 ε 计算辐射功率
  7. 风道外组件 — 停滞区按箱内平均温度 + 自然对流估算
  8. 2D 温度场 — 50×N 网格 + 高斯扩散 + 风道冷却 + 边界冷却 + Laplacian 平滑
  9. 能量平衡校核 — Q_air + Q_wall + Q_rad vs Ptot，计算偏差
  10. 特殊工况检测 — 风道阻塞 / 自然对流 / 停滞区

🔄 ICEPAK 工况点分析

仿真后自动显示（有进气风扇时）：

  • 风扇铭牌风量 — 自由送风（ΔP=0）的最大风量
  • 实际工作风量 — 接入系统后的工况点风量，带铭牌百分比
  • 工况点静压 — 风扇需要克服的压降
  • 阻力分解 — 散热孔 ΔP + 内部流阻 ΔP 分别列出
  • 阻力分流 — 每条风道路径的流量和阻力，合并风道标注 "(N合1)"
工作原理：风扇 P-Q 曲线（线性降）与 系统阻力曲线（k·Q² 抛物线）的交点 = 实际工作点。
散热孔多 → k 小 → 交点右移 → 风量大。散热孔少/开孔率低 → k 大 → 风量受限。

📝 仿真分析

自动生成完整文字分析报告，包含：

  • 电箱概述（尺寸 + 模块数 + 总功率）
  • 气流配置描述（各风扇/散热孔参数）
  • 风量模型说明（P-Q 曲线法，铭牌→工况点）
  • 壁面散热 + 辐射散热分析
  • 能量平衡校核（"仿真收敛良好"或警告）
  • 风道网络统计（路径数/合并数/流量范围）
  • 停滞区警告（距风道 >80mm 的模块）
  • 超限/警告/合格判定 + 优化建议
  • 模块温度排序（从热到冷）
典型优化建议逻辑
• 风道阻塞 → "建议在对面增加排气风扇或散热孔"
• 模块超限 → "建议①增大风扇风量 ②增加散热孔面积 ③降低模块发热功率 ④换大箱体"
• 辐射占主导 → "可考虑增大发射率（黑色氧化处理）提升辐射散热"

📄 导出PDF报告

点击 📄 导出PDF报告 打开新窗口，浏览器自动弹出打印对话框，选择 「另存为 PDF」 即可保存。报告为 A4 排版的正式分析报告，包含 10 大章节：

  1. 项目概要 — 电箱尺寸、材料、环境条件
  2. 布局视图 — 按当前视图截图的布局图（3D 视图导出三维图，含温度场、气流箭头、风道路径）
  3. 内部模块配置 — 各模块外形、材料、功率、热阻明细表
  4. 散热配置 — 风扇 + 散热孔参数清单

💡 实用技巧

1. 快速评估散热是否足够

先看 合格/警告/超限 卡片 → 再看 能量平衡 偏差 → 最后看分析块的优化建议。

💡 合格判定采用双判据：裕度 ≥15°C 或 ≥20% 许用温升（Tmax−Ta），满足其一即合格。Tj 结温仍使用 15°C 单一阈值。

2. 结温 Tj 与参数关系

完整热链： 芯片结(Tj) ─Rjc→ 壳体(Tcase) ─Rdev→ 空气(Tair)
　　　　　　　　　　　　　 壳体(Tcase) ─ε辐射→ 箱壁(Twall)

Rjc（结→壳热阻）：越小越好。Tj = Tcase + Pheat×Rjc，Rjc 越大则芯片比壳体越烫。Rjc 取决于封装工艺（陶瓷基板+覆铜可低至 0.1，普通塑封高达 1.5+）。选模块时尽量选低 Rjc。

ε 发射率（壳体表面辐射效率）：越大越好。Q_rad = ε×σ×A_rad×(Tcase⁴−Twall⁴)，辐射帮壳温降低 → P_net↓ → Tcase↓ → 间接拉低 Tj。

两者联动关系：ε 通过降低 Tcase 来间接降低 Tj，但 Rjc 决定了 Tj 和 Tcase 之间的"鸿沟"有多大。如果 Rjc 很大（如 1.5），即使 Tcase 正常，Tj 仍可能超限——壳温安全 ≠ 芯片安全。

场景TcaseTj风险
ε高 + Rjc小低接近Tcase✅ 理想
ε高 + Rjc大低远高于Tcase⚠️ 壳温安全但芯片过热
ε低 + Rjc小高接近Tcase⚠️ 壳温已高
ε低 + Rjc大高极高🔴 最危险

3. 优化散热的优先级

  1. 加排气风扇/散热孔（消除阻塞）→ 效果最显著
  2. 增大风扇风量 → 提高 C_air，降低空气温升
  3. 增大散热孔面积/开孔率 → 降低系统阻力 k_sys
  4. 模块改用铝壳 + 散热片 → 降低 Rdev
  5. 调整模块布局 → 发热大的放上游、发热小的放下游
  6. 增大箱体 → 增加壁面散热面积

4. 理解风道分流

多个进气风扇 → 多路气流在箱内分流、绕过模块、在排气处汇合。流量按 电阻分流原理 分配：阻力小的路径获得更多风量。并联运行时重叠风道会自动合并。

5. 自然对流 vs 强制风冷

不设风扇时，工具自动进入自然对流模式（Q_eff=100 L/min）。此时散热主要靠壁面传导和辐射。模块 Rdev 应使用"自然对流"推荐值（比强制风冷高 2~3 倍）。

6. 辐射散热与材料的关系

当模块发射率 ε 较高（塑料可达 0.85~0.90）且壳温较高时，辐射散热可能超过对流散热。分析块会提示「辐射占主导」。

⚠️ 反直觉事实：导热最好的金属（铜 k=385、铝 k=200）反而辐射最差（ε=0.05~0.10），因为表面太光滑。而几乎不导热的塑料（k=0.3）辐射却很强（ε=0.90）。

解决方案：对铝壳做黑色阳极氧化/烤漆处理，ε 可从 0.10 提升至 0.85，同时保持高导热——这就是工业散热器都是黑色的原因。

铝合金2000.10🔴 差🟢 强
不锈钢160.20🟡 中等🔴 弱
钢板500.30🟡 中等🟡 中等
塑料0.30.90🟢 最强🔴 极差
